# 🎵 SQLite Chinook Music Store – 50 SQL Practice Questions

## 📌 Project Overview
This project is a structured SQL practice project built using **SQLite** on a **Music Store (Chinook) database**.  
It contains **50 SQL questions** ranging from **basic to advanced level**, designed to strengthen real-world SQL querying and data analysis skills.

This project is ideal for:
- SQL beginners to advanced learners
- Interview preparation
- Hands-on practice with relational databases

---

## 🛠️ Technologies Used
- SQLite
- SQL
- DB Browser for SQLite
- Git & GitHub

---

## 🗂️ Database Description
The database simulates a digital music store and includes data related to:
- Artists, Albums, Tracks, and Genres
- Customers and Employees
- Invoices and Invoice Items
- Playlists and Media Types

All tables are connected using proper relational keys.

### 🔹 Basic Level (1–20)

### 🔹 Intermediate Level (21–35)
- Multi-table JOINs
- GROUP BY and HAVING
- Subqueries
- Data aggregation and analysis
- Business-oriented SQL queries

### 🔹 Advanced Level (36–50)
- Complex JOINs
- Common Table Expressions (CTEs)
- Analytical queries
- Customer and sales insights
- Report-style SQL queries
